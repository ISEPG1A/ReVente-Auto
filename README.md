# Ultra (déploiement)

Ce projet PHP (DocumentRoot `public/`) inclut un `Dockerfile` pour être déployé facilement sur **DigitalOcean App Platform**.

- Voir `DEPLOY_DIGITALOCEAN.md` pour le guide pas-à-pas.
- Pour un déploiement sur VPS (Droplet), suivez une pile LAMP et pointez le VirtualHost vers `public/`.
